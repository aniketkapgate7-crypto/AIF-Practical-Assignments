## Overview

This repository contains Python implementations for 25 Artificial Intelligence lab assignments across five curriculum units, 
reframed into real-world engineering scenarios spanning smart-city infrastructure, autonomous robotics, constraint-based scheduling, 
diagnostic expert systems, fuzzy control, and evolutionary optimization.

All scripts use the Python standard library (`collections`, `heapq`, `random`, `math`, `time`) with zero external dependencies.
